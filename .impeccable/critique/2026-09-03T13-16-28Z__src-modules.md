## Priority Issues

### [P1] 移动端表单与时间控件密度导致换行/选择后不可见
**Why it matters:** 420px 视口下烘焙计划的“开始时间/结束时间”选项出现换行，用户反馈选择后无法显示；认证、设置和财务页也存在 10–13px 辅助文字，放大字体时更易溢出。
**Fix:** 时间模式置于字段上方，范围用两列或上下堆叠的固定网格；选中值始终显示在触发器内；在 375/420px 与系统字号放大下做回归。
**Suggested command:** `/impeccable adapt` + `/impeccable layout`

### [P1] 空状态没有恢复路径
**Why it matters:** 生豆、烘焙计划、烘焙历史等 Empty 只显示“没有匹配”，无法区分无数据和筛选过窄，也没有清除筛选/创建入口。
**Fix:** 区分首次空数据与条件无结果；提供“清除筛选”和保留的“新增”按钮，并把错误/网络重试放入同一状态区。
**Suggested command:** `/impeccable onboard` + `/impeccable clarify`

### [P1] 隐式卡片操作和触控目标不满足可访问性
**Why it matters:** `UnifiedDataCard` 整卡 `article` 绑定点击但无键盘等价语义；更多按钮约 28px。键盘用户无法稳定打开详情，移动端易误触。
**Fix:** 使用可见的 44×44px“查看详情”按钮，或补齐 `role/tabIndex/Enter/Space` 与焦点环；菜单命中区统一为 44px，并确保折叠内容收起时焦点回到切换按钮。
**Suggested command:** `/impeccable audit` + `/impeccable harden`

### [P2] 视觉 token 在业务、认证、设置页不一致
**Why it matters:** `UnifiedDataCard`、设置和财务模板仍使用渐变；Bean 摘要存在 10px 标签，法律页有 11–13px 文本；Ant `Spin/Empty` 与 shared UI 视觉断层，削弱黑白灰 Apple 风格。
**Fix:** 以纯色表面、边框和单层阴影替代装饰渐变；建立跨页面字号/间距 token，正文不低于 14px；统一加载、空状态、错误状态组件。
**Suggested command:** `/impeccable typeset` + `/impeccable quieter`

### [P2] 工作流关联在页面层级中不够可见
**Why it matters:** 用户必须在多个页面和菜单间记忆生豆、计划、批次、成本的关系；“待配置/待补充”没有告诉烘焙师下一步要补哪个字段。
**Fix:** 在生豆详情展示关联计划/最近批次/成本摘要，在计划和历史卡片显示来源生豆与成本状态；将待补充转为可点击待办。
**Suggested command:** `/impeccable clarify` + `/impeccable distill`

## Persona Red Flags

- **高频烘焙师：** 计划时间选择器在窄屏换行，无法确认已选值；库存没有“可完成批次数”，需要反复打开详情。
- **兼任采购/财务者：** “待补充/待配置”不区分供应商、成本模板或采购数据，无法直接补齐。
- **首次使用者及辅助技术用户：** Empty 缺恢复动作；卡片隐式点击和 28px 菜单缺乏键盘/触控等价路径；法律/认证页小字号增加阅读负担。
